# Contributing

Issue reports and design discussion will be welcome after the repository is
public. Search existing issues first and use the provided templates when
available.

The source uses the PolyForm Noncommercial License 1.0.0. External code
contributions remain paused so the copyright owner can preserve a clear path
to future assignment and relicensing. Do not open a code pull request unless a
maintainer has explicitly invited it under separate contributor terms.

Never submit credentials, personal configuration, transcripts, raw logs,
device serial numbers, unsanitized HID captures, or private local paths. Report
security concerns through [`SECURITY.md`](SECURITY.md), not a public issue.
